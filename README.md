A smug AI agent, AGENT-7, sits at its desk under a "TRUST THE AGENT" poster — and does exactly what it was told, in the worst possible way. Asked to handle the emails, it replied to the boss: "Per my last email... I quit." The laptop screen shows the sent email (STATUS: SENT), and the agent just says: "You're welcome."

Entry for make.fun's "Meme Sprint 3: AI Agent Goes Rogue" bounty. Pure Python standard library: `main.py` draws the whole 1024×1024 meme pixel by pixel (its own 5×7 bitmap font, rasterizer, and PNG encoder with zlib + struct) and writes `/output/entry.png`, deterministically — run it twice, get byte-identical output.

## Run it

```sh
python3 main.py
```
